# Skills

本包发现技能元数据并生成按需读取目录，尚未接入 Runtime、Agent、Session 或 tools。

调用方显式提供 `[]Source`，用 `Load` 获得 `Result.Skills` 和 `Result.Diagnostics`，再用 `FormatForPrompt` 生成名称、简介和文件位置目录。没有默认来源、正文缓存或技能执行功能；`AllowedTools` 仅记录声明，不授予权限。

- 来源须为目录；相对路径基于进程工作目录，不展开 `~` 或环境变量。来源顺序和目录名称排序决定优先级，同名保留首个有效项，并返回指向保留项的 `collision` 诊断。
- 只发现精确名称 `SKILL.md`，发现后停止该目录递归，包括格式无效时。跳过隐藏子目录和 `node_modules`，不解释 ignore 文件。显式指定的隐藏根仍扫描。
- 来源内链接只跟随到来源真实根内；真实目录访问集合阻止循环，最大深度为 64。成功解析的同一文件按文件身份去重，包括重名败者；无效文件不占去重位置。
- 元数据读取上限为 64 KiB（含分隔行），支持 UTF-8 BOM 和 CRLF，使用 `go.yaml.in/yaml/v3` 一次解析。正文不会进入结果；缓冲读取可能预读少量正文。
- 名称缺失或为空字符串时使用所属目录名，须符合 1–64 个小写 ASCII 字母、数字和单个分隔连字符；显式名称不同于目录名仅警告。简介非空且最多 1024 个 Unicode 字符；可选 compatibility 非空且最多 500 字符。字段类型严格校验，metadata 为字符串映射；未知字段不保留。
- `disable-model-invocation: true` 保留加载项，但不进入提示目录。目录字段用标准库 XML 转义；没有可见技能时返回空字符串。

正文和附件由宿主已有文件读取能力按需读取，相对资源路径基于 `Skill.BaseDir`，脚本不会自动运行。目录扫描不保证并发替换一致性，也不是安全沙箱；正文及附件读取仍须沿用宿主权限和路径规则。
